# 发布前代码复查

日期：2026-10-21。范围为首个公开源码版本 0.1.0。以下是实际检查范围，不代表第三方安全审计。

## 已修复

| 问题 | 处理 |
| --- | --- |
| 菜单栏动态时间视图启动时陷入布局更新循环 | 改用普通图标与文本，时钟在模型中定时更新 |
| 仅有菜单栏入口时难以找到登录界面 | 增加启动可见的独立窗口 |
| 日期和卡片名称在中文地区混用英文 | 声明中文资源并集中地区格式化；未知服务端名称保留 |
| 确认弹窗缺少操作上下文 | 展示账号、用量、更新时间、所选卡片到期时间及不可撤销提示 |
| 确认期间账号、卡片或额度可能变化 | 执行前重新读取，核对账号及目标卡片 |
| 多个实例可能同时生成不同幂等键 | 文件锁内读取或创建一次操作，原子落盘 |
| 迟到的旧结果可能清除较新的操作 | 清除时同时匹配账号和幂等键 |
| IDE 环境可能携带其他账号凭证 | 子进程环境改为运行与网络配置白名单 |
| 请求超时后可能一直复用卡住的传输 | 关闭当前传输，下一次刷新重新握手 |
| 服务端错误可能包含隐私详情 | 界面仅展示错误码，不展示原始协议错误 |
| 仓库包含个人 Xcode 用户设置和签名团队 | 不再跟踪用户设置，忽略本机产物，移除当前项目签名团队 |

## 验证

环境：Xcode 27.1、Codex CLI 0.163.0、Apple Silicon。本次 16 项测试全部通过：15 项离线测试和 1 项临时未登录 CLI 检查；Release 无签名构建通过。

- Release 配置的 macOS `xcodebuild` 构建通过，禁用代码签名，仅检查源码构建。
- 离线测试覆盖窗口计算、未知数据、多桶解析、地区格式、卡片可用性、存储损坏、重启复用、并发实例和迟到结果。
- 本地假 App Server 覆盖握手、账号读取、错误详情脱敏、超时断线与重连。
- 可选真实 CLI smoke 仅以新的临时未登录目录握手并读取账号状态，不使用现有账号。
- 原型阶段用户已确认真实登录、用量和重置卡展示正常；中文面板经过只读界面检查。
- GitHub Actions 只运行离线核心测试，不安装 CLI、不登录账号、不消费卡片，也不提供签名构建。

## 保留的限制

- **真实重置未验收**：开发过程不点击账号持有人的卡片、不触发真实消费。幂等接口的真实服务行为依赖官方协议；本地测试不能替代服务端验收。
- 尚未验证令牌长期刷新、所有套餐、所有 macOS 版本或 Intel 硬件；当前只有本机实际运行证据。
- 界面主要是简体中文；英文资源用于格式与服务端名称回退，尚未完整翻译所有用户提示。
- 不提供历史曲线、开机启动、临期或偏移系统通知，也没有签名、公证、安装包或自动更新。
- 菜单栏按产品要求仅显示最近读取的用量，数据新鲜度在面板查看。
- App Server / 服务端能力与接入规则会变化。开源代码许可证不等于商业或托管服务的认证使用许可。

## 公开内容检查

提交仅包含源代码、测试、项目配置和文档，不包含真实账号截图、Runtime / State、登录 URL、令牌或构建产物。保留的 Git 提交署名属于原仓库提交元数据；公开快照移除了本机用户配置。
