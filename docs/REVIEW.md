# 发布前代码复查

日期：2026-10-21。范围为首个公开源码版本 0.1.0。以下是实际检查范围，不代表第三方安全审计。

## 未发布改动复查 — 2026-10-21

- 已修复：状态栏偏移未检查用量新鲜度。现在与面板共用 `UsageMonitor.isStale`，读取失败、超时未更新或周期结束时不显示偏移，辅助功能读数同步处理；仍保留最后读取的用量与独立可算的时间进度。
- 已修复：右键配置窗口保存一次性额度快照。所有设置入口改为持有同一个可观察的 `UsageMonitor`，预览随账号、所选额度、刷新结果和时钟更新，无需重新打开窗口；状态栏与预览共用时钟及失效判断。
- 状态栏专项回归覆盖失效、刷新恢复和无数据。
- 验证边界：测试未操作真实账号切换或消费重置卡；原生右键交互仍需人工验收。

### 多维复查跟进

- 已修复：确认页打开后，刷新可能将 A 卡操作切换为 B 卡的未决重试。现在 UI 与模型传递同一不可变确认对象；账号、卡片或重试键不匹配时禁用并拒绝发送。落盘仅创建新操作，不接管并发出现的记录。
- 相关回归覆盖 A/B 卡切换、预检期间出现同卡/异卡记录、同卡重试键被替换、卡片详情消失后保持原键重试，以及并发新建只允许一笔成功。
- 确认对象修复验证：31 项测试中 30 项通过、1 项可选 CLI 检查跳过；无签名 Release 构建通过。消费相关回归仅运行本地假可执行文件，未访问真实重置接口。
- 已修复：断线后退出账号先恢复连接，只有服务端退出成功才清除账号和用量；失败时保留原状态。
- 已修复：重试弹窗、错误提示与 README 说明重试仍是原写操作，可能完成首次消费，并保留不可撤销提示。
- 隐私范围按最终产品要求收敛为邮箱：开关位于齿轮和状态栏右键菜单，面板及确认框隐藏邮箱，其他数值及操作不遮盖或禁用；装饰仪表图标不再提供固定 50% 的辅助功能描述。
- 测试改进：核心测试纳入实际 `UsageMonitor`，注入临时偏好及本地假可执行文件，覆盖退出重连、退出失败保留、超时重试复用持久化键，以及账号变化/卡片消失时不发送消费请求。假服务不启动真实 CLI、不访问真实账号。
- 多维复查跟进时的验证：26 项测试中 25 项通过、1 项可选 CLI 检查跳过；本地无签名 Release 构建和补丁格式检查通过。协议与界面两个 subagent 对当轮修复进行了只读复核，未发现当时范围内的明确回归。随后按邮箱隐藏的新要求移除了旧的全量遮盖测试。
- CI 增加无签名 Release 应用构建；本地同等构建命令通过。远程工作流需在提交后验证，不把配置完成表述为远程 CI 已通过。
- 接入边界已按 2026-10-21 的官方认证说明更新；清理了仅在设计讨论中成立的方案代号。

| 确认弹窗缺少操作上下文 | 展示账号、用量、更新时间、所选卡片到期时间及不可撤销提示 |

| 多个实例可能同时生成不同幂等键 | 文件锁内读取或创建一次操作，原子落盘 |
| 迟到的旧结果可能清除较新的操作 | 清除时同时匹配账号和幂等键 |

## 验证

环境：Xcode 27.1、Codex CLI 0.163.0、Apple Silicon。本次 16 项测试全部通过：15 项离线测试和 1 项临时未登录 CLI 检查；Release 无签名构建通过。

- Release 配置的 macOS `xcodebuild` 构建通过，禁用代码签名，仅检查源码构建。
- 离线测试覆盖窗口计算、未知数据、多桶解析、地区格式、卡片可用性、存储损坏、重启复用、并发实例和迟到结果。
- 本地假 App Server 覆盖握手、账号读取、错误详情脱敏、超时断线与重连。
- 可选真实 CLI smoke 仅以新的临时未登录目录握手并读取账号状态，不使用现有账号。
- 原型阶段用户已确认真实登录、用量和重置卡展示正常；中文面板经过只读界面检查。
- 当前 GitHub Actions 配置运行离线测试及无签名应用构建，不安装 CLI、不登录账号、不消费卡片。

## 保留的限制

- **真实重置未验收**：开发过程不点击账号持有人的卡片、不触发真实消费。幂等接口的真实服务行为依赖官方协议；本地测试不能替代服务端验收。
- 尚未验证令牌长期刷新、所有套餐、所有 macOS 版本或 Intel 硬件；当前只有本机实际运行证据。
- 界面主要是简体中文；英文资源用于格式与服务端名称回退，尚未完整翻译所有用户提示。
- 首版不提供历史曲线或系统通知，也未提供签名、公证和安装包。后续已增加临期通知、登录时启动及签名公证自动发布；仍不提供历史曲线、偏移通知或自动更新。真实登录项注册与跨登录启动需在签名应用上另行验收。
- 菜单栏可配置实际用量、时间进度与偏移；失效后保留最近用量，偏移显示占位，并提供待更新提示。
- App Server / 服务端能力与接入规则会变化。开源代码许可证不等于商业或托管服务的认证使用许可。
