## 下载与安装

- 需要 macOS 14+，Universal 安装包支持 Apple Silicon 和 Intel；Intel 尚未经真机验证。
- 从本页 Assets 下载 `.dmg`，打开后将 CodexWatcher 拖入 Applications；也可下载 `.zip`，解压后移动应用。
- 应用已通过 Developer ID 签名和 Apple 公证，校验值见 `SHA256SUMS.txt`。`Source code` 压缩包不包含可直接运行的应用。
- 需单独安装 [Codex CLI](https://learn.chatgpt.com/docs/app-server)，再在应用中连接 ChatGPT 账号。

独立第三方开源项目，与 OpenAI 无隶属关系；可用字段取决于账号及服务端。真实重置消费尚未验收，重置会消耗卡片且无法撤销，测试不消费真实卡片。

「满额自动 hello」默认关闭；开启后会消耗模型额度。持续满额和未知结果不会重复发送，真实服务端计时效果尚未验收。
